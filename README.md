# Orbit OS

Touch-friendly browser desktop with Notes, Sketch, Calculator, Snake, Files, a timer, Orbit Browser and Cloud Play.

## Publishing
GitHub Settings > Pages > Deploy from a branch > main > /(root).

## Local preview
Run `python3 -m http.server 8000` here and visit http://localhost:8000.

## Important limitations
This is a browser desktop, not a virtual operating system. Native apps cannot be installed. Cloud Play embeds CloudMoon; the catalogue and Roblox sign-in entry were tested, but authenticated gameplay and a physical iPad were not. Provider sign-in, queues, time limits and charges apply. Popup sign-ins are blocked; use the provider email option if available. Disconnect closes the embedded view and does not cancel provider billing.

Orbit Browser only shows sites which allow embedding. Notes and files are saved locally in the browser; export important work. No passwords or API keys are included.
