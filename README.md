# Orbit OS

Touch-friendly browser desktop for iPad and desktop browsers, with Notes, Sketch, Calculator, Snake, local Files, a timer, Orbit Browser and Cloud Play.

## Publish
In repository Settings > Pages, choose Deploy from a branch, then main and /(root). Save. The static site requires no build.

## Run locally
Run `python3 -m http.server 8000` in this directory and visit http://localhost:8000.

## Limitations
This is a browser desktop, not a virtual operating system. Native Roblox cannot be installed inside it. Cloud Play embeds the independent CloudMoon service. Its catalogue and Roblox sign-in entry were verified; authenticated gameplay and physical iPad operation were not tested. Provider limits, account requirements and charges may apply. Pop-up sign-ins are blocked; use the provider email option if available.

Orbit Browser can only display sites that allow embedding. Local data stays in browser storage; export important files and notes. Clearing site data can remove it. No passwords or API keys are included.
